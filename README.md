# UBO / 一燈內容總站

這個 repo 是 UBO / 一燈相關公開內容的 GitHub Pages 總站。

## 資訊架構

- `index.html`：總目錄與分類入口
- `events/<date-topic>/`：整理版頁面，放簡短逐字稿、重點摘錄、框架與案例
- `transcripts/<date-topic>/`：完整逐字稿頁面，保留長篇時間序列
- `content/`：可重用的內容資料
- `assets/`：共用樣式或媒體資產

## 目前收錄

- `events/2026-05-24-business-mindset/`：一燈商業思維線下聚整理版
- `transcripts/2026-05-24-business-mindset/`：一燈商業思維線下聚完整逐字稿

## 發布策略

未來所有 UBO / 一燈內容集中在同一個 repo，依 `events/`、`transcripts/` 與後續 `topics/` 分層。
